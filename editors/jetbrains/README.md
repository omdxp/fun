# JetBrains support

JetBrains IDEs can use TextMate bundles for syntax highlighting.

1. Open **Settings → Editor → TextMate**.
2. Click **+** and select `editors/jetbrains/Fun.tmbundle`.
3. Apply and reopen a `.fn` file.

For LSP, use the JetBrains "LSP" plugin and point it at `fls` (if you prefer LSP-based features).
